# Klo Finder

Eine kostenlose, werbefreie Android-App von Your Needs – für die wirklich wichtigen Dinge.

**Öffentliche Testversion 0.3.1 · Android 9 oder neuer · Datenabdeckung Deutschland.**

[APK herunterladen](https://github.com/yourneeds-app/klofinder-releases/releases/latest/download/Klo-Finder.apk) · [Versionshinweise und Prüfsummen](https://github.com/yourneeds-app/klofinder-releases/releases/latest) · [Datenschutz](PRIVACY.md) · [Impressum](https://yourneeds.app/rechtliches?lang=de#impressum)

Zum Herunterladen ist kein GitHub-Konto erforderlich. Lade die APK herunter, öffne sie und bestätige die Installation in Android. Falls Android fragt, erlaube deinem Browser bzw. Dateimanager einmalig die Installation aus dieser Quelle. Es gibt keine stille Installation.

Die reguläre App wird separat neben dem bisherigen Debug-Prototyp installiert. Dessen Favoriten und lokale Sterne bleiben dort erhalten und werden nicht automatisch übernommen. Die reguläre App startet mit einer leeren Merkliste. Weitere reguläre Updates verwenden denselben Klo-Finder-Schlüssel und erhalten die Daten dieser regulären App.

## Funktionen und Updates

Karte und Liste, GPS-Suche mit genauer oder ungefährer Android-Freigabe, 1/3/5-km-Umkreis, Filter, lokale Favoriten/Sterne und bewusst gestartete Fußweg-Navigation in einer externen Karten-App. Kein Konto, keine Werbung, keine Freitextkommentare oder Fotos.

Beim Start prüft die App höchstens einmal täglich, ob eine neue Version verfügbar ist. Unter Einstellungen/Info kann die Prüfung manuell gestartet werden. „Herunterladen“ lädt erst nach deiner Entscheidung; Prüfsumme, App-Paket, Version und Signatur werden vor der Installation geprüft. „Installieren“ öffnet nach eventueller Android-Freigabe den Systemdialog, den du selbst bestätigst. Ein vollständiger Download bleibt nach einem Neustart verfügbar; unterbrochene Downloads werden erneut geladen.
